# Revisão da área “Seções do currículo” em ResumeEditor.tsx

## Investigação concluída

1. **Repetição visual** — `ResumeEditor.tsx:1080-1085` renderiza o título e, na linha seguinte, o rótulo do tipo. Para seções padrão, `section.title` é igual a `sectionLabels[section.type]`, então “Habilidades” aparece duas vezes.
2. **Duplicatas estruturais** — `addSection` (`ResumeEditor.tsx:534`) e `changeSectionType` (`585`) não impedem criar ou converter uma seção para um tipo já existente. `createSection` (`resume-document.ts:272`) só evita colisão de IDs, não de tipos; `normalizeSection` (`469`) também não deduplica tipos. Por isso é possível salvar duas seções `skills`.
3. **“Cursos, certificações e projetos”** — é apenas o rótulo do tipo `courses` (`resume-document.ts:126`). Os tipos `courses`, `certifications` e `projects` já existem no modelo frontend e no enum backend (`ResumeSectionType.php`). Não é necessário alterar API, banco ou migrations.
4. **Ordem** — a lista usa `doc.sections.map` (`ResumeEditor.tsx:1056`) e a pré-visualização usa `document.sections.filter` (`ResumePreview.tsx:440`). A ordem já corresponde; a pré-visualização apenas oculta seções vazias/ocultas.

## Implementação

### 1. `frontend/src/lib/resume-document.ts`

- Alterar `sectionLabels.courses` de `'Cursos, certificações e projetos'` para `'Cursos'`.
- Adicionar `legacySectionLabels` com o rótulo antigo, para compatibilidade.
- Adicionar `canonicalSectionTitle(type, title)` que normaliza a capitalização quando o título corresponde, sem diferenciar maiúsculas/minúsculas, ao rótulo atual ou legado. Ex.: `"idiomas"` → `"Idiomas"`, `"HABILIDADES"` → `"Habilidades"`.
- Usar essa normalização em `normalizeSection`, garantindo que currículos salvos antigos sejam carregados com nomes padronizados.
- Exportar `isDefaultSectionTitle(type, title)` para o editor saber quando pode atualizar o título ao trocar o tipo, incluindo o rótulo legado de `courses`.

### 2. `frontend/src/features/resume-editor/ResumeEditor.tsx`

- `addSection`: bloquear tipos não-`custom` já existentes, com mensagem orientando a editar a seção existente ou criar uma personalizada.
- `changeSectionType`: bloquear conversão para tipo não-`custom` já usado por outra seção; usar `isDefaultSectionTitle` ao atualizar o título.
- Menu “Adicionar seção”: desabilitar tipos padrão já adicionados, exibir “Adicionada” com check, manter `custom` sempre disponível e incluir nota explicativa.
- Seletor “Tipo de conteúdo”: desabilitar opções de tipos já usados por outra seção, indicando “(já adicionada)”.
- Lista de seções: exibir o título principal; mostrar o tipo apenas quando for diferente do título; exibir selo “Oculta” quando aplicável; incluir selo discreto “Tipo duplicado” para tipos não-`custom` repetidos em currículos já salvos.
- Atualizar o texto de ajuda para registrar que seções vazias ou ocultas não aparecem no A4, mas a ordem é a mesma.

### 3. Preservação e compatibilidade

- Nenhuma seção ou conteúdo existente é removido automaticamente.
- Títulos legados de `courses` permanecem como estão; apenas novas seções usam “Cursos”.
- A capitalização é normalizada somente para rótulos conhecidos; títulos personalizados não são alterados.
- Duplicatas já salvas continuam existindo, mas ficam sinalizadas e novas duplicatas são impedidas.
- Reordenação, visibilidade, edição e exclusão permanecem inalteradas.
